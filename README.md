# LessonsWidget — виджет «Следующий урок»

Android-виджет для экрана: показывает следующий урок, кабинет, таймер
«через N минут», подсказку о перемене («дальше: Химия в 312») и текущий урок.

## Скачать APK
Свежая сборка — в [релизах](https://github.com/Abobik35/LessonsWidget/releases):
скачай `LessonsWidget.apk`, открой его на телефоне и разреши установку
из этого источника.

## Возможности
- Виджет «Следующий урок»: кабинет, учитель, перемены, живой отсчёт минут,
  полоска прогресса урока.
- Импорт недельного расписания из «Моя Школа» (myschool.mosreg.ru) через Госуслуги.
- Быстрое обновление: расписание перезаписывается за секунды, учителя
  догружаются фоном по дням.
- Замены учителей — строго по текущей неделе; автоматическая сверка
  каждое утро в 6:45 и после любых изменений.
- Визуальные состояния: идущий урок — синяя рамка, прошедший — серый значки.
- Тёмная / светлая / системная тема (приложение и виджет), настройки,
  раздел «Частые вопросы» с обучением по импорту.

## Стек
- Kotlin 2.0 + Jetpack Compose (экран редактора)
- Glance (нативный виджет)
- Room (локальное хранилище расписания)

## Как собрать
1. Открой папку проекта в **Android Studio** (Ladybug или новее), JDK 17 идёт в комплекте.
2. Дождись Gradle-синхронизации. Если Studio ругнётся на отсутствие
   `gradle-wrapper.jar` — согласись на восстановление wrapper-а или выполни в
   терминале: `gradle wrapper --gradle-version 8.9`.
3. Запусти конфигурацию `app` на эмуляторе или реальном устройстве.
4. Добавь уроки в приложении.
5. На рабочем столе: долгое нажатие → «Виджеты» → «Расписание» → перетащи виджет.

## Структура
```
app/src/main/java/com/nastlo/lessonswidget/
├── LessonsApp.kt            — Application + база
├── data/                    — Room: сущность, DAO, база
├── logic/NextLessonCalculator.kt — «следующий урок» / «идёт пара» / «перемена»
├── widget/                  — Glance-виджет, приёмник, планировщик обновлений
└── ui/                      — редактор расписания (Compose)
```

## Как работает обновление
Виджет не тикает каждую секунду: будильник (AlarmManager) срабатывает в моменты
начала/конца каждого урока (в пределах завтра), плюс каждые 30 минут
гарантированно системным `updatePeriodMillis`. Между срабатываниями таймер просто
«стареет на пару минут». Тап по виджету открывает редактор и сразу обновляет данные.

## Импорт расписания из «Моя Школа»
Кнопка **«Импорт»** в редакторе:

1. Встроенный браузер открывает `myschool.mosreg.ru` — вход через Госуслуги
   (капча/СМС обрабатывает сам сайт). После входа приложение считывает куку
   `aupdtoken` — это токен официального API «Моя Школа». Он хранится только
   на телефоне; можно и вставить его руками.
2. Выбор ученика (детей берём из профиля семьи).
3. Загрузка расписания за 4 недели (`periods_schedules`), учитель и кабинет
   уточняются по каждому уникальному уроку (`lesson_schedule_items`).
4. Предпросмотр недельного расписания без дублей → «Добавить в расписание».
   Галочка «Очистить текущее расписание» по умолчанию включена.

Если что-то пошло не так — на экране есть кнопка «Показать сырой ответ» с JSON.
Код API-клиента повторяет заголовки официального приложения (по OctoDiary-py, MIT).
